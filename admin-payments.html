Review sample

This opens a static sample review screen for design purposes only. No approve, reject, or real payment review exists anywhere in this prototype.

How review will work

  • The quote and expected crypto amount always come from server records, never from anything the browser supplies.
  • An administrator manually verifies the network, recipient address, amount, transaction success, confirmations, and that the transaction hash has not already been used.
  • Submitting a transaction hash never means the payment is approved.
  • Approval will later require server-side authorization, an audit log entry, and atomic activation of the related Fan Card, Membership, Donation, or Booking.
  • Private keys, seed phrases, and other recovery material are never requested, exposed, or stored anywhere in this system.
