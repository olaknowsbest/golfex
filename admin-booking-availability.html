Save

Saving requires authenticated admin access and server-side backend validation. No window, block, or note is created, changed, or persisted anywhere in this static prototype.

How saved availability will work

  • Only an administrator can create or update availability. The backend expands a saved date range into individual bookable slots only for the selected weekdays — never from a free-form customer request.
  • Excluded dates and blocked time windows override the recurring schedule and are never offered or selectable to customers.
  • Existing customer reservations are never overwritten when availability is edited.
  • Overlapping availability rules are detected and rejected before saving.
  • Price is calculated as duration × hourly rate, subject to the minimum duration set here.
  • All timestamps are stored in UTC and displayed in the timezone selected above.
  • Saving a complete date-range schedule is one atomic server-side transaction.
